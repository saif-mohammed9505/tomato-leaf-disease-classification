# 🍅 Tomato Leaf Disease Classification Using CNN

## 📌 Project Overview

This project focuses on **tomato leaf disease classification using a Convolutional Neural Network (CNN)**.

A custom CNN model is trained on tomato leaf images to classify them into multiple disease categories. The project covers dataset preparation, image preprocessing, data augmentation, CNN model development, model training, image prediction, and model saving.

---

## 🎯 Objectives

The main objectives of this project are:

- 🍅 Classify tomato leaf images into disease categories
- 🧠 Build a CNN model for image classification
- 🔄 Apply image preprocessing and augmentation
- 🏋️ Train the model using TensorFlow/Keras
- 🔮 Predict the disease category of a new tomato leaf image
- 💾 Save the trained model for later use

---

## 🗂️ Dataset

The project uses a tomato leaf image dataset organized into class-specific folders.

The dataset is divided into:

| Dataset | Percentage |
|---|---:|
| 🏋️ Training | 80% |
| 🔍 Validation | 10% |
| 🧪 Testing | 10% |

The dataset is split using **Split-Folders** with a seed value of `1234`.

The notebook configures the model for **10 classes**.

---

## 🖼️ Image Configuration

The CNN uses:

- Image size: **256 × 256**
- Channels: **3 (RGB)**
- Classification type: **Multi-class**
- Number of output classes: **10**

---

## 🔄 Data Preprocessing

The image generators apply pixel rescaling and augmentation.

### Image Preprocessing

- 🔢 Pixel rescaling by `1/255`
- 📐 Shearing
- 🔍 Zooming
- ↔️ Horizontal flipping

The same augmentation configuration is used for the training, validation, and test generators in the notebook.

---

# 🧠 CNN Model

A custom Convolutional Neural Network was developed for tomato leaf disease classification.

### Architecture

- Conv2D — 32 filters
- MaxPooling2D
- Conv2D — 32 filters
- MaxPooling2D
- Flatten
- Dense — 128 neurons
- Output Dense layer — 10 classes with Softmax

### Model Configuration

- Optimizer: Adam
- Loss Function: Categorical Crossentropy
- Metric: Accuracy
- Batch Size: 32
- Maximum Epochs: 100

---

## 🏋️ Model Training

The CNN model is trained using the prepared training dataset and validated using the validation dataset.

The notebook records the training duration and uses the trained model for image prediction after training.

---

## 🔮 Prediction Workflow

The prediction process follows these steps:

1. 📤 Load a tomato leaf image
2. 🖼️ Convert the image into an array
3. 🔢 Prepare the image for model input
4. 🧠 Pass the image through the trained CNN
5. 📊 Generate prediction probabilities
6. 🏆 Select the class with the highest probability
7. 📋 Display the predicted disease class

The predicted class is obtained using the class indices generated by the training dataset.

---

## 💾 Saved Model

The trained CNN model is saved in two formats:

- `tomato_leaf_disease.h5`
- `tomato_leaf_disease.keras`

These files can be used to load the trained model for future predictions or deployment.
